# juhee200/homebrew-tap

[리뷰엉이(review-owl)](https://github.com/juhee200/review-owl) 메뉴바 앱을 Homebrew로 설치하는 tap입니다.

```bash
brew install --cask juhee200/tap/review-owl
```

업데이트는 `brew upgrade --cask review-owl`, 삭제는 `brew uninstall --cask review-owl`입니다. 설정과 기록까지 지우려면 `--zap`을 붙입니다.

v0.5.0까지의 이름은 pr-ai-reviewer입니다. 옮기는 방법은 [리뷰엉이 README 5.4절](https://github.com/juhee200/review-owl#54-v050-이하pr-ai-reviewer에서-옮기기)에 있습니다.
